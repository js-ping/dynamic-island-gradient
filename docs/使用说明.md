# 岛影 · 使用说明

> 给壁纸顶部加一层渐变蒙版，让 iPhone 的灵动岛和状态栏自然融进画面。
>
> **纯前端，零依赖。整个工具就是一个 `index.html` 文件，Windows / Mac 双击就能用。图片全程留在你自己的电脑里。**
>
> 本说明书已经内置在里面了 —— 点顶栏右上角的「说明书」按钮随时打开。

## 一、这个工具解决什么问题

iPhone 从 14 Pro 开始有了「灵动岛」—— 屏幕顶部中间一块永久的黑色药丸。

问题是：如果你用一张明亮的照片当锁屏，顶部那块黑色硬件就会**硬生生切**在画面里，非常出戏。

厂商给的做法是让壁纸顶部自动变暗，但系统只对自带壁纸做这件事，你自己下的图不管。

这个工具就是干这件事的：**在壁纸顶部盖一层从实到透的渐变**，上端刚好糊住灵动岛和状态栏，往下平滑溶进原来的画面。看起来就像照片本来就是这么拍的。

```
原图                          处理后
┌──────────────┐              ┌──────────────┐
│  天空  ☀️      │              │▒▒▒▒▒▒▒▒▒▒▒▒▒▒│ ← 纯色区（盖住灵动岛）
│              │   ──►        │▒▒▒▒▒▒▒▒▒▒▒▒▒▒│
│              │              │▓▓▓▓▓▓▓▓▓▓▓▓▓▓│ ← 过渡区
│   山  ⛰️      │              │  山  ⛰️       │ ← 原图不变
└──────────────┘              └──────────────┘
```

## 四、每个参数是什么意思

### 渐变颜色

| 选项 | 说明 | 什么时候用 |
|---|---|---|
| **纯黑（默认）** | 用接近纯黑（RGB 8,10,12）覆盖 | 万能选项，任何壁纸都不会突兀 |
| **同色采样** | 自动取壁纸顶部中间区域的**平均色** | 天空是蓝的、晚霞是橙的 —— 用这个过渡最自然 |
| **自定义颜色** | 自己用取色器挑一个 | 想跟画面主色呼应，或者做特殊色调 |

> 采样是取「顶部中间三分之一」的矩形，缩放到 1×1 像素得到的**平均值**，所以不会被某一根树枝、某一颗星星带偏。

### 覆盖强度

`0% ~ 100%`，默认 **100%**。

控制最顶部那层的**不透明度**。

- `100%` = 完全盖住（推荐，灵动岛区域最干净）
- `60%~80%` = 只是压暗，还能隐约看到图片纹理
- 低于 `40%` = 只起到「加一点氛围」的作用

### 完全覆盖高度

`0% ~ 30%`，默认 **4.2%**。右边实时显示**当前这张图**对应的像素值。

这一段是**纯色**，从图片最顶上往下量。

- iPhone 17 Pro Max 的状态栏 + 灵动岛，大约吃掉 **4% ~ 6%** 的高度
- 建议刚好盖住状态栏下沿就行，盖太多会显得头重脚轻
- 这里的百分比是按**图片高度**算的，所以不管你用 1320×2868 的原图还是缩放过的图，效果都一样

### 渐变结束高度

`1% ~ 60%`，默认 **13%**。

纯色区下边缘到这个高度之间，颜色由**实**渐变到**透**。再往下就是原图。

- 这个值必须大于「完全覆盖高度」（拖到头会自动互相约束）
- `完全覆盖 4%` + `渐变结束 13%` → 大约 9% 的高度用来过渡，多数壁纸都合适
- 想要更强的一体感 → 拉到 20%~30%
- 想要克制、几乎看不出处理过 → 8%~12%

### 过渡曲线

决定颜色**怎么**散开。下面那张小图就是当前曲线的形状：**线越靠上 = 覆盖越重**。

| 曲线 | 手感 | 适用 |
|---|---|---|
| **缓出**（默认） | 一开始就快速散掉，覆盖感最轻 | 大多数情况 |
| **线性** | 从头到尾均匀过渡 | 想要绝对均匀的数学感 |
| **缓入** | 颜色往下探得更远，中段更实 | 顶部内容是纯色（天空/白墙）时很好看 |
| **S 型** | 两端都平缓，中间过渡最快 | 最柔和，几乎看不出交界 |

### 辅助选项

| 开关 | 作用 |
|---|---|
| **显示灵动岛参考框** | 在预览上叠一个虚线框，标出灵动岛的大概位置，以及「安全区」水平线。按 iPhone 17 Pro Max 的比例算，**只作位置参考**，不会画进导出的图片。 |
| **抗色带噪点** | 在渐变区域叠一层肉眼不可见的极细噪点。深色渐变在 OLED 屏上容易出现一圈一圈的「色带」，这个开关能把它打散。默认开启，关掉也看不出区别。 |

### 导出

| 项 | 说明 |
|---|---|
| **格式** | JPEG（体积小，推荐）/ PNG（无损，体积大） |
| **画质** | JPEG 专用，默认 95%。设壁纸 90% 以上足够，肉眼分不出 |

导出文件名会自动带上参数，方便你回溯：

```
Daoying_black_4.2-13_easeout_20261013-0825.jpg
          │      │      │        └─ 导出时间
          │      │      └─ 曲线
          │      └─ 完全覆盖% - 渐变结束%
          └─ 颜色模式
```

## 六、常见问题 FAQ

**Q：图太大/太多处理不动？**
A：不会。v2.0 换掉了逐像素的算法，改用浏览器原生的渐变合成，1320×2868 的原图拖滑杆也是实时出图。

**Q：导出的图会变小吗？**
A：不会。导出就是原图的分辨率，一个像素都不缩。

**Q：为什么我选了「同色采样」，顶部颜色和画面不太搭？**
A：采样取的是图片**最顶部中间三分之一**的平均色。如果你的壁纸顶部恰好有个深色物体（树枝、鸟），采样就会被它带偏。这时候改用「纯黑」或者手动「自定义颜色」更稳。

**Q：HEIC 格式的壁纸打不开？**
A：Chrome / Edge / Firefox 都解不了 HEIC，只有 Safari 可以。先把图转成 JPG 即可。工具会给出提示，不会静默失败。

**Q：Windows 电脑上能用吗？**
A：能，和 Mac 上完全一样，双击 `index.html` 就开。唯一要留神的是：如果双击后打开的是记事本而不是浏览器，
说明这台电脑的 `.html` 关联被改过 —— 右键选「打开方式」指定 Chrome / Edge，或者双击同目录的 `启动.bat`。

**Q：手机能用吗？**
A：能，两种办法：
一是把 `index.html` 存进 iCloud / 网盘，用手机浏览器打开；
二是 Mac 上双击 `启动.command`，手机连同一个 WiFi，浏览器访问终端里显示的地址。
布局已经做了移动端适配。

**Q：图片会被上传吗？**
A：不会。整个工具没有任何网络请求，代码里没有一行 `fetch` / `XMLHttpRequest`。你可以断网使用，也可以右键「查看源代码」自己核对。

**Q：会不会把效果画错、或者污染原图？**
A：处理后的像素只写在上层画布上，原图所在的画布从不改动。下方「渐变结束高度」以外的像素，测试验证过与原图**逐字节一致**。

## 七、数据安全声明

- **无网络请求**：不联网、不上传、不埋点、不加载任何第三方资源（字体、图标库、统计脚本统统没有）。
- **无本地留存**：图片不会被写入磁盘。只有你的参数设置存在浏览器 `localStorage` 里，随时可以在浏览器设置里清掉。
- **完全可审计**：整个工具就是一个 `index.html`，你可以用任何文本编辑器打开，从头读到尾。
- **开源**：MIT 协议，随便改、随便用、随便分发。
